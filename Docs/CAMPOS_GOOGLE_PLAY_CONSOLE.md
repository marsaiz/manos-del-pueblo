## 📋 CAMPO 3: Cualquier otra información necesaria para acceder a tu aplicación

```
INSTRUCCIONES DE ACCESO Y PRUEBA

═══════════════════════════════════════════════════════════════

🔐 CREDENCIALES (PINes de seguridad)

• PIN Administración: 4628
• PIN Gestión de Productos: 1234
• PIN Eliminar Artesano: 919345

═══════════════════════════════════════════════════════════════

👨‍💼 ACCESO COMO ADMINISTRADOR

1. Abrir app → Pestaña "Sobre Nosotros" (última pestaña)
2. Desplazar hacia abajo → Sección "Administración"
3. Tocar "Gestionar Artesanos"
4. Ingresar PIN: 4628
5. Tocar "VERIFICAR"

FUNCIONES DISPONIBLES:
• Crear artesano: Pestaña "Añadir" → Completar formulario
• Editar artesano: Pestaña "Lista" → Ícono lápiz azul → PIN: 4628
• Eliminar artesano: Pestaña "Lista" → Ícono basura rojo → PIN: 919345
• Gestionar categorías: Pestaña "Categorías" → Crear/editar/eliminar

═══════════════════════════════════════════════════════════════

🎨 GESTIÓN DE PRODUCTOS (Como Artesano)

1. Abrir menú hamburguesa (☰) arriba a la izquierda
2. Seleccionar "Administrar Productos"
3. Ingresar PIN: 1234

FUNCIONES DISPONIBLES:
• Crear producto: Botón "+" → Completar formulario (hasta 3 fotos) → PIN: 1234
• Editar producto: Tocar ícono lápiz en producto → Modificar → PIN: 1234
• Eliminar producto: En edición → Botón rojo "ELIMINAR" → PIN: 1234

═══════════════════════════════════════════════════════════════

🔍 OTRAS FUNCIONALIDADES A PROBAR

• Búsqueda: Barra superior en pantalla principal
• Filtros: Botones de categorías horizontales
• Favoritos: Ícono corazón en productos
• Compartir: Ícono compartir en detalle de producto
• Contacto: WhatsApp/Instagram/Facebook en perfil artesano
• Cursos: Pestaña "Cursos" para ver talleres disponibles

═══════════════════════════════════════════════════════════════

⚠️ NOTAS IMPORTANTES

• La app NO requiere registro ni login tradicional
• Los PINes protegen funciones administrativas
• Sesión administrativa dura 30 minutos
• Máximo 3 imágenes por producto
• Eliminación de artesano incluye todos sus productos e imágenes
• Las imágenes antiguas se eliminan automáticamente al reemplazar

═══════════════════════════════════════════════════════════════

📞 CONTACTO

Email: contacto@manos-del-pueblo.ar
```
